## Mandatory pre-action supervision admission

Before substantive Work, run `npm run supervision:admit:runtime -- --worker <id> --input <request.json>`; proceed only when `mayExecute` is exactly true and preflight `allowed` is true. After exact setter submission, `--applied-selection` proves `SET_REQUEST_ONLY`, not readback. `SET_REQUEST_SUFFICIENT` permits null observations; `DO_NOT_ENABLE_FAST` is request intent, not verified off. Required readback, mismatch, or unavailable Fast enablement fails closed. The adapter has no task-creation bridge and cannot launch. Version 3 requires a verified Chat receipt, separately hashed current directive, zero spend, and exact profile. Chat decides; Work executes. `QUEUED_FOR_PROVIDER_RELAY` remains blocked until authenticated delivery.
