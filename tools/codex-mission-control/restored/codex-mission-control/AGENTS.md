## Mandatory pre-action supervision admission

Before substantive bounded Work, run `npm run supervision:admit:runtime -- --worker <id> --input <request.json>` for source-bound admission and durable model/effort/Fast preflight. Proceed only when `mayExecute` is exactly true and preflight `allowed` is true. Supply `--applied-selection <json>` only after the launcher submits those exact setters; it is not readback. The current adapter has no task-creation bridge, so omit it and fail closed. New work requires a verified Chat receipt, exact directive, zero-spend scope, and explicit `workExecutionProfile`; any defect or material unverifiability stops. Chat owns decisions and prose; Work only executes. `QUEUED_FOR_PROVIDER_RELAY` remains blocked until an authenticated provider receipt proves delivery.
