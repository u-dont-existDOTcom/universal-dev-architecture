## Mandatory pre-action supervision admission

Before Work authors any Chat-owned semantic decision, run `npm run supervision:admit:runtime -- --worker <id> --input <request.json>`; proceed only when `mayExecute` is exactly true and binds a verified Chat receipt to a bounded zero-spend directive. A denial routes internally and stops that action—never ask Joel to relay or approve it. Chat retains GitHub changes, architecture, review, supervision, and substantive prose; Work is execution-only. `QUEUED_FOR_PROVIDER_RELAY` remains blocked until an authenticated provider receipt proves delivery.
