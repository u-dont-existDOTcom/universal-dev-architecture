# Universal Development Architecture

Canonical cross-project store for reusable development and agent-workflow lessons.

## Purpose

Project repositories keep their own exact evidence, incident notes, experiments, and local decisions. This repository receives only lessons that are genuinely transferable across projects.

## Start here

Fresh agents should read `LESSON-INDEX.md` before substantial implementation, debugging, automation, or agentic workflow work. Do not rely on remembered lesson lists from prior chats.

## Core invariant

Chat memory is not durable project state. Substantive work should close its learning loop in the project's canonical repository before completion, and genuinely transferable lessons should be promoted here.

## Authority

1. Current project owner correction / current project requirements
2. Current project repository state and exact evidence
3. Current universal lessons in this repository
4. Older summaries and remembered chat context

A universal pattern never overrides a project's explicit current requirement.
