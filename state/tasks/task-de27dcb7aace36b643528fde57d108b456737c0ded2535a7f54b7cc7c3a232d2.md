# Mission Control owner dashboard: what each task's supervisor is doing, an honest supervisor button, and a first screen that shows what needs the owner

- Branch: `claude/mc-honest-supervisor-link-20261010`.
- Task ID: `pr-356`.

## Goal

- The owner can reach a worker's supervisor chat from the dashboard, or sees plainly that none is linked; the button never opens the ChatGPT home page or a demo address.
- The first screen shows what needs the owner's decision first, then the alarms Mission Control raised itself in plain words with the task's supervisor at hand, then the tasks; project and watch internals sit in the details.
- The owner can see what each task's supervisor is doing: what it was last asked, whether that went out, the answer, and the ChatGPT chat where it ran; and whether supervisor chats can be reached at all.

- Owner: on 2026-10-10 the owner reported that the dashboard's supervisor chat button only opens chatgpt.com, so the dashboard was unusable for reaching supervisors, and on 2026-10-11, after the deploy of main, that the dashboard is still not useful: its "Your decisions and actions" listed Mission Control's own alarms (missing owner-action telemetry, an overdue non-owner step) as if they were owner decisions.
