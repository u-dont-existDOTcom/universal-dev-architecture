## Completed

- **`lib/owner-task-registration.ts`.**
  - Parses the four answers exactly: goal; may use, must never and done when, one item per line. Extra fields are refused; the passphrase is split off before parsing.
  - Records the owner source: canonical JSON of the answers and the form's standard lines, its SHA-256, `OWNER_REATTESTED`, an owner-session locator.
  - Derives the outcome, contract and reconciliation mechanically. Every text in them is an owner answer or a standard line the form shows.
  - A SYSTEM record sets the connection to `OFFLINE_CONFIGURED`.
  - A repeat records nothing. Other answers for a registered id are refused; an id with any records is refused, naming what is there.
- **`lib/owner-task-passphrase.ts`** (review P0). The daemon registers only with the owner's registration passphrase, checked against a scrypt verifier next to the database; five wrong ones lock it for 15 minutes; no verifier means registration is off. **`scripts/set-owner-task-passphrase.ts`** installs a verifier made on the owner's computer.
- **`lib/store.ts`.** Registration markers (event ids, owner-session locator) are refused on every path except `appendOwnerTaskRegistration`, so `POST /events` can't forge one (review P0).
- **`lib/owner-task-source.ts`.** A registered task is under the current supervision rules from the start, in the store and the terminal comparator (review P1).
- **`lib/projection.ts`, `lib/owner-view.ts`.** A registered task with nothing else recorded shows as "Registered · waiting for its supervisor", not as missing telemetry (review P1). The enrollment change is withdrawn: a task joins the fleet watch when its supervisor publishes a work queue.
- **`app/api/workers/route.ts` POST.** Owner session only, with same-origin and CSRF; the owner bearer gets 403. It relays the body unread.
- **`daemon/server.ts` POST `/workers`.** Owner producer and the passphrase; invalid JSON is a 400 and never logged.
- **UI.** `app/workers/new/page.tsx`, `components/RegisterTask.tsx` (passphrase field, the standard lines shown), a dashboard header link, styles.
- **README.** "Registering a task in the owner's own words", with what the check covers and what it doesn't.
- **Tests.** `tests/owner-task-registration.test.ts`, 10 tests; `tests/owner-task-registration-daemon.test.ts`, a real daemon. Twelve mutations, each failing a test (see Evidence).
