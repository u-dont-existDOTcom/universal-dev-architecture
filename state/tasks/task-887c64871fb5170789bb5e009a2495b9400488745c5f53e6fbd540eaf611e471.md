## Active lesson contract

- Renewal instead of no expiry is marked as the assistant's choice: without an expiry, a controlled takeover could never complete.
- An expired lease is never revived; a configured successor stops renewal of the old lease.

## Completed

- `lib/provider-submission-authority.mjs`: the scheduler's `renewLeaseIfDue()` checks and renews in one serialized transaction.
- `lib/submission-authority-runtime.ts`: `renewLeaseIfDue()` renews only the configured lease, only while it is valid and single-active with no safety halt, and only once less than half of the window remains, extending only its expiry; `leaseAutoRenewalDays()` reads `MISSION_CONTROL_SUBMISSION_LEASE_AUTO_RENEW` (on by default, `off` to stop) and `..._DAYS` (2-60, default 14).
- `daemon/server.ts`: renews when due at start (after the authority's own startup) and hourly after that, logging each renewal and failure.
- `tests/submission-authority-runtime.test.ts`: renewal while valid survives a restart; an expired lease is never revived; renewal can be switched off; a lease ten seconds from expiry still renews; a renewal queued behind another transaction while the lease runs out is refused; a configured successor that cannot activate stops renewal; settings are bounded.
- `.env.example`, `patterns/mission-control-multi-host-submission-scheduling.md`, the requirement record and `tests/test_mission_control_lease_auto_renewal.py`.

## Current checkpoint

- Ready for review. Not merged or deployed.
- Review, 2026-10-31: GitHub's Codex reviewer was out of quota, so Codex reviewed `48b59555` locally (Codex CLI, read only). One major finding: the runtime checked the lease outside the scheduler's transaction, so a renewal queued behind another operation could revive a lease that had run out meanwhile. One minor: the first renewal came 30 seconds after start, too late for a lease about to run out. Both are fixed in the maintainer's second commit: the scheduler checks and renews in one serialized transaction, the first renewal runs at start, and a regression test reproduces the race (it fails against the earlier code).
