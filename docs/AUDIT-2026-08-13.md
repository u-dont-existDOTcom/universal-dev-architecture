## GitHub account constraints

The connected GitHub app can read and write repository contents but does not have repository-administration scope. Branch protection, rulesets, and default workflow-token permissions therefore require authenticated local `gh` execution or manual repository administration.

Protected branches are available for public repositories on GitHub Free. Private personal repositories require GitHub Pro or another qualifying plan; a `403` must be treated as a real unavailable control, not a success.

## Required sequence

1. Merge the universal baseline through a pull request.
2. Upgrade active software repositories through separate pull requests.
3. Redesign Pangram's direct-to-main metadata processor before protecting `main`.
4. Apply safe repository settings and branch protection through authenticated `gh`.
5. Re-audit all repositories and record implemented versus unavailable controls.
