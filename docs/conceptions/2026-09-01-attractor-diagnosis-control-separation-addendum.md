# Attractor correction addendum — diagnosis is present, control is absent

Date: 2026-09-01
Authority: direct owner correction
Status: ACTIVE; supersedes any framing that treats better critique or defect awareness as the missing capability

## Exact correction

GPT already knows what it is doing wrong. It can identify the polished symmetry, explanatory closure, abstraction, semantic orbit, and other recurring defects accurately. The failure is that it cannot reliably stop producing them. The learned distribution exerts a strong attraction toward the same high-probability continuation basin.

## Consequence

Do not model the problem as:

```text
writer lacks diagnosis
-> add critic
-> return critique to writer
-> writer improves
```

Use:

```text
writer can diagnose the defect
+ ordinary generation remains magnetized toward it
-> verbal awareness is not a causal control
-> intervene on search, distribution, representation, training signal, or source material
```

The critic can be perfectly correct and operationally useless. A second model can add another accurate description of the same failure while leaving the generating distribution unchanged. Debate may couple the agents more tightly to the shared basin.

## Experimental implications

1. `diagnosis_accuracy` is not a primary outcome and should not be rewarded as progress.
2. No arm receives critic language, self-explanation, or a growing prohibition list.
3. Fresh execution and n8n isolation test only whether rare out-of-basin samples are being suppressed by state contamination; they are not presumed to overcome learned magnetism.
4. Hermes is admissible only as a mechanically distinct isolation/search implementation, not because it reflects or remembers more.
5. If independent sampling still converges, stop orchestration experiments and move to controls that can alter the effective distribution:
   - diversity-aware or avoidance-aware decoding;
   - activation/representation steering on an open model;
   - preference adaptation or fine-tuning from accepted versus rejected examples;
   - quality-diversity search over explicit structural behavior descriptors;
   - owner-authored or owner-spoken source transformation rather than free generative reconstruction.
6. A model explaining the correct failure after producing it is evidence of the diagnosis-control dissociation, not evidence that one more reflection cycle will work.

## Evidence posture

Research on intrinsic self-correction shows that error detection and correction are separable and that self-correction without an external mechanism can fail or degrade performance. Inference-time activation steering and diversity-aware decoding demonstrate that model behavior can be changed by intervening below ordinary natural-language self-instruction. These literatures support the mechanism distinction but do not establish that any specific technique will solve Joel-compatible Somatic prose.

## Decision

Retain the matched direct-versus-n8n isolation test as a bounded diagnostic. Do not treat a null result as surprising. Precommit that a shared failure moves the work to distribution-level intervention or non-generative owner-source composition, not to another critic, persona, model debate, or longer prompt.
