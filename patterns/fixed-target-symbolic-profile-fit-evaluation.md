# Fixed-Target Symbolic Profile Fit Evaluation

## Purpose

Evaluate how well one or more symbolic personality systems (for example astrology, Human Design, BaZi, or related typologies) describe a pre-existing behavioral profile without reverse-engineering the target from the systems being tested.

This is a descriptive-fit workflow, not evidence that the symbolic systems are scientifically predictive.

## Core anti-cherry-picking sequence

1. **Freeze the target first.** Recover or write the behavioral profile before calculating or interpreting any candidate system. Preserve concrete traits, contradictions, context dependence, and known failure modes.
2. **Preserve an independent conception snapshot.** Record the target dimensions and any candidate explanatory mechanism before literature/system exposure if novel synthesis is being attempted.
3. **Scan established work.** Check primary/authoritative system definitions, established calculation rules or implementations, relevant scientific validation literature, and known cognitive-bias concerns such as Barnum/Forer effects.
4. **Calculate from source data.** Use reproducible ephemerides/calculation rules rather than generic online summaries when feasible. Preserve exact birth-time/location assumptions and time-zone conversion.
5. **Score both hits and misses.** For every high-weight target dimension, record direct fit, partial fit, contradiction, or no prediction. Penalize generic statements and post-hoc reinterpretation.
6. **Separate descriptive coverage from evidentiary independence.** If two systems reuse the same underlying astronomical variables (for example Human Design and tropical planetary longitudes), do not count their agreement as independent corroboration.
7. **Run sensitivity checks.** Test whether plausible uncertainty in time, date, location, ayanamsha, house system, or other system-specific settings changes the key classification.
8. **Prefer discriminative matches.** Weight a narrow, behaviorally specific match more than broad statements that would fit many people. Explicitly flag interpretations that become convincing only after flexible metaphorical translation.
9. **Identify the residual.** After ranking systems, state where the top system fails, overpredicts, underpredicts, or requires another system to compensate.
10. **Benchmark against alternatives.** Compare the best symbolic system with the strongest competing system and, when useful, with a deliberately wrong/nearby chart or timestamp to estimate discriminability.

## Recommended output

- Fixed behavioral target used
- Exact calculation assumptions
- Ranked systems by descriptive fit (heuristic, not probabilistic)
- Most discriminative matches for the leader
- Material mismatches for the leader
- Best complementary system and what it uniquely adds
- Dependency warning where systems share inputs
- Birth-data or parameter sensitivity
- Scientific-validation status
- Optional falsification test: blind comparison against nearby/wrong cases

## Scoring discipline

Use qualitative grades or transparent heuristic scores only. Never present a fit score as a probability that the system is true. Suggested dimensions:

- specificity of match
- breadth of target coverage
- contradiction penalty
- amount of interpretive flexibility required
- independence from other compared systems
- stability to plausible input uncertainty

A useful system should not win merely by generating more statements. Normalize for statement breadth and treat unexplained target features as residuals rather than silently ignoring them.

## Reuse rule

For future profile-system comparisons, begin with this fixed-target workflow rather than re-learning the anti-cherry-picking and sensitivity architecture from scratch.
