# Contributing

This public, high-risk policy repository is owner-maintained. Bug reports and
bounded technical feedback are welcome, but do not submit policy changes or a
pull request without explicit maintainer confirmation.

Before proposing an authorized change, read `AGENTS.md`, `LESSON-INDEX.md`,
`docs/INDEX.md`, `patterns/codex-github-operating-system.md`, and
`state/CURRENT-STATE.md`. Preserve exact provenance, transfer limits,
supersession, hosted-control truth, and project-specific authority boundaries.
Run both exact commands in `.github/codex-repository.json` and use the pull
request template.

Security reports follow `SECURITY.md`. Never submit credentials, private user
material, protected project evidence, or unnecessary raw logs.

Publication, a contribution, or review does not grant reuse rights. See
`LICENSE.md`; separate contribution or reuse terms require an explicit written
owner decision.
