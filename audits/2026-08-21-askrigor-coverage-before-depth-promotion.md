## Promotion boundary

This promotion records a transferable owner correction from the exact merged
AskRigor source above. The cited sanitized audit, digest, causal regressions,
pull request, and merge commit establish project provenance without preserving
raw conversation or private research content. They establish implementation
and tested failure controls, not semantic completeness or substantive truth.

## Failure class

A broad decision-oriented evidence task selected a small, concentrated set of
sources and then audited those sources deeply. The retrieval depth was real,
but the selected set did not adequately cover the materially different option
and program landscape. The resulting synthesis risked treating one generic
category as though it represented distinct programs, contexts, outcomes,
failure trajectories, and alternatives.

More pagination or deeper analysis of the same narrow set could not repair the
selection error. The missing control was an explicit pre-selection coverage
inventory plus a synthesis lock that considered diversity and uncovered
classes, not only completion of each selected source.

## Transfer rationale

The distinction between selection coverage and per-item audit depth is not
specific to health research or YouTube. The same failure can affect:

- vendor, library, model, and product comparisons;
- benchmark and evaluation-set construction;
- software and configuration test selection;
- incident and failure-mode reviews;
- qualitative and community-source research;
- policy, evidence, and option-landscape synthesis.

The transferable rule is therefore stored in
`patterns/coverage-before-depth-in-selection.md`. AskRigor's treatment classes,
health policies, provider contracts, query counts, and source-specific fields
remain project-local.

## Existing-work map and composition

- **Already solved/reusable:** Cochrane supplies intervention grouping and
  complexity controls; PRISMA-ScR supplies evidence-mapping and selection
  reporting; maximal marginal relevance supplies a relevance-plus-novelty
  selection precedent; theoretical sampling supplies a gap-driven expansion
  precedent; NIST supplies explicit set-coverage criteria for testing.
- **Partially solved/adaptable:** each precedent addresses one layer, but none
  by itself supplies a general agent-workflow synthesis lock.
- **Incompatible:** fixed cross-domain item quotas and claims of statistical
  representativeness are not justified for purposive, access-bounded
  discovery.
- **Novel remainder:** a small orchestration contract joining a material class
  inventory, decision-relevant fingerprints, iterative discovery, explicit
  uncovered state, and a fail-closed synthesis boundary.
- **Disposition:** compose the established controls; do not claim a novel
  sampling method.

## Universal projection

- Pattern: `patterns/coverage-before-depth-in-selection.md`
- Router: `LESSON-INDEX.md` and `docs/INDEX.md`
- Regression: `tests/test_coverage_before_depth_pattern.py`
- Completed plan: `docs/exec-plans/completed/2026-08-21-coverage-before-depth.md`
- Canonical state: `state/CURRENT-STATE.md`

The Universal regression is a durable documentation-contract check. It can
catch deletion of the coverage inventory, fingerprint, lock, limits, or causal
examples. It cannot prove that an arbitrary downstream agent follows the rule.
Repeated or decision-critical workflows need a project-local executable
controller that derives the lock from actual ledger state.

The originating implementation review also exposed reusable enforcement
failures: renamed caller IDs could manufacture diversity; an aggregate screened
count could hide an omitted landscape; free-text fingerprints could claim
completeness; a missing-field sentinel could diverge across prose and code;
hand-flattened completion labels could replace literal source receipts; one
aggregate lock could conflate selection with item depth; retryable errors could
masquerade as terminal boundaries; unjustified hard blocks could become a
select-everything quota; invalid records could inflate aggregates; and accepted
input could produce an oversized response. The promoted pattern therefore
requires normalized field-derived signatures, stable receipt-linked source IDs,
reciprocal batch/candidate records, decision-impact omission thresholds,
deterministic receipt projections, terminal/retryable/recovery state,
valid-record counters, bounded transport, separate component locks,
capability-aware fallbacks, and causal single-failure regressions.

A second adversarial pass found that those controls also need to reject four or
more sources concentrated in one or two normalized fingerprints, unsupported
`not decision-relevant` waivers, caller-terminal labels over live continuation
state, class-level follow-up that hides a program-level gap, hypotheses lost
because only the latest discovery batch is checked, receipt projection that is
implemented but absent from the callable production surface, and
schema-accepted results that exceed the response limit. The Universal pattern
and regressions include these as explicit causal failure classes.

A third adversarial pass verified two additional trust-boundary failures.
First, unsigned or caller-editable continuation state could skip pages or forge
an offset, while a lone continued page could be mislabeled as proof of a
complete retrieval chain. The transferable repair is authenticated opaque or
server-held chain state plus truthful cumulative chain receipts that prove the
first page, contiguous progression, reconciliation, and terminal completion.
Second, a caller-supplied size or scope label could try to deactivate hard
coverage checks even when the linked ledger contained twenty or more candidates
or a concentrated selected set. Applicability must come from authoritative task
scope and valid ledger structure; an untrusted label cannot waive the
invariant.

## Privacy and evidence limits

- This promotion does not preserve raw chat, identities, credentials, private
  provider output, or individualized health content.
- The originating project evidence must be a sanitized repository artifact,
  not reconstructed from conversation memory.
- The pattern does not prove completeness or representativeness.
- Diverse sources are not necessarily credible sources.
- A passing lock certifies only the project's declared coverage boundary; it
  does not establish substantive truth, efficacy, safety, or causality.
- Project-specific source availability, intervention categories, thresholds,
  and public-surface rules remain authoritative within AskRigor.
